# MABC Compliance Guard — 대회 규정 준수 가드레일

이 스킬은 「Making AI Beneficial 챌린지」 규정을 작업 전·후로 스스로 점검하기 위한
가드레일이다. 규정을 대신 해석하지 않으며, 의심되면 멈추고 사용자에게 묻는 것을
기본 태도로 한다.

## 0. 빠른 확인 (매 작업 전 30초)

아래 3개만 먼저 체크한다. 하나라도 걸리면 작업을 멈추고 사용자에게 확인한다.

- [ ] 지금 사용하는 LLM이 **Solar Pro 4**인가? (외부 모델 호출 없음)
- [ ] 지금 사용하는 개발 도구가 **TimelyAI(MABC 워크스페이스)** 또는 **Hermes Agent** 뿐인가?
- [ ] **API 키·시크릿을 코드·배포물·응답 JSON에 노출**하고 있지 않은가?

## 1. 대회 개요 (기억용)

| 항목 | 내용 |
|---|---|
| 대회명 | (대한민국을 이롭게) Making AI Beneficial 챌린지 (MABC) |
| 플랫폼 | TimelyAI (리타임리) — 스킬·에이전트 제작 |
| LLM 제한 | **Solar Pro 4만** (예선·결선 공통). 외부 모델 호출 실격. fallback 예외 있음 |
| 개발 도구 | **TimelyAI + Hermes Agent(Solar Pro 4 연동)만** 허용. Claude Code, Cursor, Codex 등 외부 AI 코딩 도구 금지 |
| 외부 공개 API | 허용 (공공데이터포털, 지도, 날씨 등) — 제5조 3항 |
| API 키 | 소스코드·배포물에 **노출 금지** (제9조 6항). 노출 피해는 참가자 책임 |
| 제출물 요건 | 실제로 동작해야 함. 동작하지 않으면 평가 제외 (제5조 1항) |
| 데이터 수집 | 개발 기록(대화·입출력) 수집 동의 필요. 미동의 시 결선 참가 불가 (제10조 1항) |

## 2. 예선 규정 체크리스트 (제5조·제6조)

### 2-1. 제출물 요건 (제5조)

- [ ] 제출물은 **TimelyAI 서비스 내 MABC 워크스페이스**에서 제작한 결과물인가?
  - 타 서비스에서 만든 skill은 실격 (제5조 1항)
- [ ] **Solar Pro 4만** 사용했는가? Claude/GPT/Gemini 등 외부 모델 호출 없음?
  - 외부 모델 호출 시 실격 (제5조 2항)
  - 단, fallback 모델 예외는 있음 (이미지 입력 등에서 타 LLM 제외 fallback은 허용)
- [ ] 공개 오픈소스 외부 API를 사용했다면, 제5조 3항에 따라 허용 범위인가?
- [ ] 제출물이 **실제로 동작**하는가? (동작하지 않으면 평가 제외)
- [ ] 참가자 본인(팀)의 창작물이며, 제3자 지식재산권 침해 없음?
- [ ] **금지 콘텐츠 미포함** (제5조 5항):
  - [ ] 법령 위반·공서양속 반반 내용 없음
  - [ ] 차별·혐오·폭력·음란·타인 명예훼손 내용 없음
  - [ ] 타인 개인정보를 동의 없이 포함·노출하지 않음
  - [ ] 타인 저작물·상표를 권리자 허락 없이 사용하지 않음
- [ ] 오픈소스·외부 라이브러리·생성형 AI 산출물 사용 시 라이선스 조건 준수, 요청 시 출처 공개 가능?
- [ ] 동점 시 먼저 제출된 제출물 우선 (제5조 7항) — 마감 임박보다 여유 있게 제출

### 2-2. 다작 정책 (제6조)

- [ ] 1인당 최대 3개 스킬까지 제출 가능 (팀 3인 = 최대 9개)
- [ ] 실질적 기능 없거나 동일·유사한 제출물을 형식적으로 반복 제출하지 않았는가?
  - 해당 시 심사·집계 제외 가능
- [ ] 순위 반영: 제출 주체(개인·팀)의 **최고점 1개 스킬을 대표작**으로 반영

## 3. 결선 규정 체크리스트 (제7조~제12조)

### 3-1. 결선 진출 및 자격 (제7조)

- [ ] 결선 진출 자격은 예선 심사 결과로 부여, 운영진 공식 채널(이메일) 통지
- [ ] 결선 진출 팀 구성원 추가·교체·탈퇴는 운영진 사전 승인 없이 불가

### 3-2. 결선 과제 및 제출물 (제8조)

- [ ] 결선 과제는 제7조 3항의 스킬을 기반으로 한 **서비스 MVP를 제작, 독립적으로 배포**
- [ ] 제출물 포함 내역 (제8조 2항):
  - [ ] ① 누구나 접근 가능한 **공개 URL** (사용자 화면 갖춘 형태)
  - [ ] ② **PRD 등 개발 명세**
  - [ ] ③ **소스코드** (저장소 링크 또는 압축본)
  - [ ] ④ 운영진이 정하는 제출 양식에 따른 자료
- [ ] **제출 마감: 2026년 9월 16일(수) 18:00**. 마감 이후 제출·수정 불가
- [ ] 결선 발표회: 팀원 중 **1인 반드시 참가** (9월 19일, 한국과학기술회관)
- [ ] 배포본 특정 정보(커밋 해시, 배포 식별자 등) 함께 제출
- [ ] 심사 종료 시까지 배포본 변경 금지, 심사 시점 서비스 접근 불가 시 평가 제외
- [ ] 배포 플랫폼 제한 없음 (Vercel 기준 교육·가이드 제공, 그 외 플랫폼 문제는 참가자 책임)
- [ ] 제5조 4~6항(창작물 요건, 금지 콘텐츠, 라이선스 준수)은 결선 제출물에 준용
- [ ] 이용자 정보 수집·처리 시 관련 법령 준수, 분쟁 책임은 참가자

### 3-3. 개발 환경 및 모델 사용 제한 (제9조) — ★가장 중요★

- [ ] **런타임에 사용하는 LLM은 Solar Pro 4만** (제9조 1항)
  - 타 모델(Claude, GPT, Gemini 등) 외부 호출 시 실격
  - 단, 플랫폼에서 이미지 등 입력 시 fallback으로 다른 모델 활용(타 LLM 제외)은 허용
- [ ] **개발 도구 제한** (제9조 2항):
  - [ ] ① TimelyAI (지정 MABC 워크스페이스)
  - [ ] ② Solar Pro 4 연동 Hermes Agent
  - [ ] **그 외 외부 AI 코딩 에이전트·어시스턴트(Claude Code, Cursor, Codex 등) 사용 금지** — 위반 시 부정행위
- [ ] MCP 활용 허용. 외부 데이터 활용 시 저작권 표기 필수. 타 LLM 활용 합성데이터 제작 금지
- [ ] 코드 편집기 등으로 직접 작성·수정 허용. 단, 제10조 검증 과정에서 설명 가능해야 함
- [ ] 공개 외부 API 사용은 제5조 3항 준용
- [ ] **API 키 등 인증정보를 소스코드·배포물에 노출 금지** (제9조 6항)
  - 노출로 인한 크레딧 손실·피해는 참가자 책임
  - → 키는 반드시 서버 측 환경변수(Vercel env var 등)로 관리, 클라이언트 소스·응답 JSON에 포함 금지

### 3-4. 개발 기록 수집 및 검증 (제10조)

- [ ] 결선 기간(2026-09-09 ~ 09-16) 동안 TimelyAI 및 Hermes Agent(업스테이지 콘솔 API)
  대화·입출력 기록이 부정행위 검증·심사 목적으로 수집·열람됨에 동의
- [ ] Hermes Agent 사용 희망 시 **별도 데이터 적재 동의 완료** 필요. 미동의 시 결선 참가 불가
- [ ] 운영진이 PRD·소스코드와 개발 기록을 대조해 정합성 검증
  - 개발 기록으로 설명되지 않는 코드·기능 포함 시 규정 외 도구·모델 사용으로 추정
  - 참가자는 운영진 요청에 따라 소명해야 함. 정당한 소명 없으면 부정행위 판정
- [ ] 운영진의 재현·검증 요청(소스코드 제공, 시연, 기록 확인 등)에 응대해야 함
- [ ] 수집된 기록은 부정행위 검증·심사 목적으로만 사용

### 3-5. 크레딧 (제11조)

- [ ] 운영진이 API 크레딧 지급. 지급 규모·방법은 공식 채널 안내
- [ ] 크레딧은 추가 지급하지 않음. 소진으로 인한 중단은 참가자 책임
- [ ] 크레딧·API 키는 지급받은 참가자(팀)만 대회 참여 목적으로 사용
  - 타인 양도·공유, 대회 외 목적 사용 금지 (제22조 9항)
- [ ] 심사 종료 후 서비스 유지 의무 없음. 잔여 크레딧 처리는 운영진 안내

### 3-6. 심사 및 데모데이 (제12조)

- [ ] 심사 기준: 심미성 아닌 **사용성** (핵심 기능 명확한 동작, 이해 가능한 화면 구성)
- [ ] 데모데이(2026-09-19): 배포된 서비스를 공개 URL 기준으로 시연
- [ ] 동점자 처리: 제5조 7항 준용 (먼저 제출된 제출물 우선)

## 4. 지식재산권 및 산출물 (제6장, 제14~15조)

- [ ] 산출물 저작권 등 지식재산권은 창작한 참가자(팀)에게 귀속
- [ ] 주최자에게 플랫폼 통한 공유·배포 등 성과 확산·교육·홍보 목적 비독점적·무상 이용 허락
- [ ] 제3자 지식재산권 침해 없음 보증. 관련 분쟁 책임은 참가자

## 5. 부정행위 및 금지 행위 (제7장, 제16~17조)

다음 행위는 부정행위(실격 사유). 작업 중 이 목록을 자주 확인한다.

- [ ] 타인 스킬·코드·산출물·아이디어 무단 도용·표절
- [ ] 타인 저작물·개인정보·계정 도용, 권리자 동의 없는 사용
- [ ] 타인 사칭, 참가 자격·연령·소속 허위 제공
- [ ] 1인 다중 계정 생성·이용, 타인 명의 참가
- [ ] 심사위원·운영진 청탁, 금품 제공, 위협 등 부정 심사 영향
- [ ] 심사·집계 시스템 취약점 악용, 부정 접근·조작
- [ ] 대회 진행 또는 다른 참가자 참가 고의 방해
- [ ] 법령·공서양속·본 규정·행동강령 반반 제출물 제출·관련 행위
- [ ] 그 밖에 공정한 경쟁 현저히 해치는 행위

## 6. 실격 사유 (제18조) — ★위험 신호★

아래 중 하나라도 해당되면 실격 가능. 작업 중 발견 시 즉시 멈추고 판단.

1. 제7장 부정행위·금지 행위 확인 (개인 또는 팀 전체)
2. 참가 자격(제3조) 미충족, 자격 관련 허위 사실 확인 (개인)
3. 제출물 정상 동작 안 함, 제출 규격·마감 등 필수 요건 위반 (해당 스킬)
4. 규정 외 모델·도구 사용, 표절·도용, 안전(유해·개인정보·금지 콘텐츠) 위반
   → 사안 중대성에 따라 결과물 또는 팀 전체 적용
5. 운영진 정당한 확인 요청(신원·연령·재현 검증 등)에 정당한 사유 없이 불응

## 7. 참가자 유의사항 (제22조)

- [ ] 공식 채널 공지 스스로 확인 의무. 미확인 불이익은 참가자 부담
- [ ] 계정·인증정보 보안은 참가자 책임. 인증정보 타인 공유 금지
- [ ] 제출물·작업 내용 별도 백업 권장. 마감 임박 장애 대비 여유 있게 제출
- [ ] 제출 전 저작권·라이선스, 개인정보 및 기밀 포함 여부 **스스로 점검**
- [ ] 타임리 별도 약관 적용됨
- [ ] 대회 관련 문의는 주최자 안내 공식 창구 이용
- [ ] 오프라인 행사(결선·데모데이) 사진·영상 촬영 등 현장 기록 가능, 초상권 동의 범위 별도 고지
- [ ] 이의제기: 심사 결과 발표일부터 3일 이내 공식 채널 서면 제기. 운영진 14일 이내 검토 회신
- [ ] 대회 제공 자료(교육자료·크레딧 등)는 대회 참여 목적으로만 사용.
  운영진 사전 동의 없이 복제/재배포·유출 금지
